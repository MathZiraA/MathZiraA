- 💼 **Estagiário de TI** na **Compre & Alugue Agora**: suporte técnico, chamados, rede e acessos. Antes, estagiei na **Tips Tecnologia**.

- 🌐 Foco em infraestrutura, cloud, cibersegurança e desenvolvimento de software.
